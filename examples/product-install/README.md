# Product Install

This Takontuku store was generated by `create-takontuku`.

## Start developing

```sh
bun install
bun run cf-typegen
bun run db:sync
bun run db:migrate:local
bun run dev
```

The local app uses Wrangler's D1 and R2 emulators. Add real Cloudflare resources only when
you are ready to deploy. See `AGENTS.md` for the project rules that coding agents should
follow.

## Build with AI

Takontuku installs reusable skills for Codex, Claude, and Cursor in `.agents/skills/` and
`.claude/skills/`. Ask an AI coding agent to inspect `AGENTS.md` first, for example:

> Buat toko online untuk bisnis kopi lokal ini. Mulai dengan rencana, gunakan workflow
> Takontuku yang tersedia, lalu implementasikan dan jalankan typecheck.

> Build a storefront for a local coffee business. Read `AGENTS.md`, choose the required
> Takontuku modules, implement the smallest complete slice, and run typecheck and lint.

After upgrading `@takontuku/core`, refresh the installed instructions with:

```sh
bunx takontuku skills install
```

## Common changes

- Change store name, locale, currency, palette, and copy in `astro.config.mjs`.
- Add or remove features with `bunx takontuku add <module>` or
  `bunx takontuku remove <module>`.
- Add store-specific starting data under `seed/`, then run `bunx takontuku db seed`.
