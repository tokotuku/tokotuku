# Service Install

This Karsa service site was generated by `create-karsa`.

## Start developing

```sh
bun install
bun run cf-typegen
bun run db:sync
bun run db:migrate:local
bun run dev
```

The local app uses Wrangler's D1 and R2 emulators. Add real Cloudflare resources only when
you are ready to deploy. See `AGENTS.md` for the project rules that coding agents should
follow.

## Build with AI

Karsa installs reusable skills for Codex, Claude, and Cursor in `.agents/skills/` and
`.claude/skills/`. Ask an AI coding agent to inspect `AGENTS.md` first, for example:

> Buat situs layanan untuk Teman Ekor. Mulai dengan rencana, gunakan workflow
> Karsa yang tersedia, lalu implementasikan dan jalankan typecheck.

> Build a service-booking site for Teman Ekor. Read `AGENTS.md`, choose the required
> Karsa modules, implement the smallest complete slice, and run typecheck and lint.

After upgrading `@karsa/core`, refresh the installed instructions with:

```sh
bunx karsa skills install
```

## Common changes

- Change service name, locale, currency, palette, and copy in `astro.config.mjs`.
- Add or remove features with `bunx karsa add <module>` or
  `bunx karsa remove <module>`.
- Add service-specific starting data under `seed/`, then run `bunx karsa db seed`.
