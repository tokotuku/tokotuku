# docs

Tokotuku UI's documentation site: Astro + Starlight.

## Development

```sh
bun run dev
```

## Status

Only a splash `index.mdx` exists so far. Per-component docs (Overview, Installation, Usage, Properties, Methods, Events, Slots, CSS Variables, CSS Parts, Accessibility, Keyboard Support, Examples, Migration Notes) get added under `src/content/docs/components/<name>.mdx` as each component in `@tokotuku/elements` ships.
