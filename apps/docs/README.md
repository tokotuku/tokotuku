# docs

Tokotuku UI's documentation site: Astro + Starlight.

## Development

```sh
bun run dev
```

The site documents installation, theming, the three core components shipped by
`@tokotuku/elements`, and all 18 application components shipped by the commerce starter. Pages
include live previews where document-level behavior allows it, plus properties, events, slots,
CSS parts, and accessibility notes.
