## Install

The starter ships its Astro components and Tailwind theme as one local workspace package.
Install the workspace dependencies once:

```sh
bun install
```

## Astro

Import components directly. They render semantic HTML and static Tailwind CSS without client JavaScript:

```astro
---
import Button from "@tokotuku/ui/Button.astro";
import "@tokotuku/ui/styles.css";
---

<Button variant="primary">Save changes</Button>
```

## Package roles

| Package | Purpose |
| --- | --- |
| `@tokotuku/ui` | Astro components plus Tailwind theme and global styles |
