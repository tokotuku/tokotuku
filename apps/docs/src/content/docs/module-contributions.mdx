title: Module contributions
description: Extend the packaged storefront and admin dashboard without bespoke page copies.

Catalog and Orders contribute to the packaged storefront and dashboard through the Takontuku
module registry. Contributions have an id, entrypoint, and optional order. The registry keeps
dependency order as the stable tie-breaker and rejects duplicate IDs.

Catalog adds the responsive collection section on the homepage, catalog metrics, low-stock
preview, and Products navigation. Orders adds the cart and checkout routes, cart affordance,
Orders navigation, and operational sales/recent-order widget. Those affordances disappear
together when a module is removed.

The dashboard never invents sales. With no real orders, the Orders widget shows a complete
zero state. Running db:seed creates six local catalog products and inventory only.
