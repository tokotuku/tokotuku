```astro
---
import TkButton from "@tokotuku/astro/TkButton.astro";
import TkCard from "@tokotuku/astro/TkCard.astro";
---

<TkCard>
  <img slot="media" src="/product.jpg" alt="Everyday widget" />
  <h2>Everyday widget</h2>
  <p>Reliable, compact, and ready for daily use.</p>
  <div slot="footer">
    <TkButton size="sm">View product</TkButton>
  </div>
</TkCard>
```

## Slots

| Slot | Purpose |
| --- | --- |
| `media` | Full-width image, video, illustration, or other leading media |
| default | Main body content |
| `footer` | Actions, metadata, or supporting content |

The footer is hidden automatically when the `footer` slot is empty.

## CSS parts

| Part | Purpose |
| --- | --- |
| `body` | Main padded content container |
| `footer` | Footer content container |

```css
tk-card::part(body) {
  gap: var(--tk-spacing-4);
}
```

## Accessibility

`tk-card` is intentionally neutral and does not assign a landmark or heading role. Use semantic headings, links, and buttons appropriate to the card's content.
