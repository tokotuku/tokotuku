```astro
---
import Button from "@tokotuku/ui/Button.astro";
import Card from "@tokotuku/ui/Card.astro";
---

<Card>
  <img slot="media" src="/product.jpg" alt="Everyday widget" />
  <h2>Everyday widget</h2>
  <p>Reliable, compact, and ready for daily use.</p>
  <div slot="footer">
    <Button size="sm">View product</Button>
  </div>
</Card>
```

## Slots

| Slot | Purpose |
| --- | --- |
| `media` | Full-width image, video, illustration, or other leading media |
| default | Main body content |
| `footer` | Actions, metadata, or supporting content |

The footer is omitted when the `footer` slot is empty.

## Accessibility

`Card` renders an `<article>` but does not invent a heading. Supply semantic headings, links, and buttons appropriate to its content.
