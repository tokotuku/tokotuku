`tk-input` combines an optional label with a native text, email, or password field.

## Properties

| Property | Type | Default | Reflected |
| --- | --- | --- | --- |
| `label` | `string` | `""` | No |
| `type` | `"text" \| "email" \| "password"` | `"text"` | No |
| `name` | `string` | `""` | No |
| `value` | `string` | `""` | No |
| `placeholder` | `string` | `""` | No |
| `required` | `boolean` | `false` | Yes |
| `disabled` | `boolean` | `false` | Yes |

## Events

The component dispatches a typed, bubbling `tk-change` event whenever the user enters text.

```ts
const input = document.querySelector("tk-input");

input?.addEventListener("tk-change", (event) => {
  console.log(event.detail.value);
});
```

Event detail:

```ts
interface TkChangeEventDetail {
  value: string;
}
```

## Methods and CSS parts

| Name | Kind | Purpose |
| --- | --- | --- |
| `focus()` | Method | Moves focus to the internal native input |
| `label` | CSS part | Optional internal `<label>` |
| `input` | CSS part | Internal native `<input>` |

## Accessibility

- The generated label is associated with the internal input using `for` and `id`.
- Required and disabled states are forwarded to the native field.
- Focus-visible state uses `--tk-color-focus-ring`.
