## Properties

| Property | Type | Default |
| --- | --- | --- |
| `label` | `string` | none |
| Remaining props | native `<input>` attributes | — |

## Events

The rendered input emits native `input` and `change` events.

```ts
const input = document.querySelector("input[name=email]");

input?.addEventListener("input", (event) => {
  console.log((event.currentTarget as HTMLInputElement).value);
});
```

## Accessibility

- The generated label is associated with the input using `for` and a stable per-render `id`.
- Required and disabled states use native field semantics.
- Focus-visible state uses `--tk-color-focus-ring`.
