`Button` renders a native `<button>` with scoped Astro styles. Use it to initiate an action, submit a form, or reset form state.


## Properties

| Property | Type | Default |
| --- | --- | --- |
| `variant` | `"primary" \| "secondary" \| "ghost"` | `"primary"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `type` | native button type | `"button"` |
| Remaining props | native `<button>` attributes | — |

## Slots

The default slot accepts the button label or inline content.

## Accessibility

- Keyboard activation and focus behavior come directly from the native button.
- Focus-visible state uses `--tk-color-focus-ring`.
- Native attributes such as `disabled`, `name`, `value`, and `aria-*` pass through.
