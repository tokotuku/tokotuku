| Name | Kind | Required | Default |
| --- | --- | --- | --- |
| `input` | Prop (`ChartInput`) | Yes | — |
| `title` | Prop (`string`) | Yes | — |
| `description` | Prop (`string`) | No | — |
| `height` | Prop (`number`) | No | `360` |
| `showTable` | Prop (`boolean`) | No | `true` |
| `actions` | Slot | No | — |

## Behavior and accessibility

- Registers only bar, line, pie, scatter, and heatmap ECharts series.
- Uses the SVG renderer and Takontuku semantic theme tokens.
- Re-renders when the document theme changes and resizes through `ResizeObserver`.
- Enables ECharts ARIA descriptions and decals.
- Renders a collapsible data table when inline values are available.
- Dispatches a bubbling `chart-select` event when a chart mark is clicked.
