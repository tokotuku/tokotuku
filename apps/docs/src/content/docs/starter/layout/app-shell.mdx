## Slots

| Slot | Purpose |
| --- | --- |
| `sidebar` | Sticky primary navigation column |
| `header` | Sticky workspace topbar |
| default | Centered main workspace content |

Below `48rem`, the shell becomes a single-column layout and the sidebar becomes a static top section.
