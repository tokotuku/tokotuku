`StoreHeader` provides the public storefront header with Home, Shop, Admin, and Cart navigation.

```astro
---
import StoreHeader from "@tokotuku/ui/StoreHeader.astro";
---

<StoreHeader current="products" />
```

## Props

| Prop | Type | Required |
| --- | --- | --- |
| `current` | `"home" \| "products" \| "cart"` | No |

## Client behavior

- Applies and persists light or dark document themes while following OS contrast modes.
- Reads `tokotuku-cart` from local storage and displays the total quantity.
- Handles clicks on `[data-add-to-cart]` buttons anywhere in the document.
- Updates matching products and briefly changes the button label to “Added”.

Because those listeners intentionally operate at document scope, this page does not mount an interactive instance inside the Starlight shell. View the complete header in the commerce example with `moon run example:dev`.
