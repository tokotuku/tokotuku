## Props

| Prop | Type | Default |
| --- | --- | --- |
| `tone` | `"neutral" \| "accent" \| "success" \| "warning" \| "danger"` | `"neutral"` |

The default slot contains the label. A badge is presentational text; add separate accessible context when color or status is not already clear from its wording.
