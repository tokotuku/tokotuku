## Props

| Prop | Type | Required | Default |
| --- | --- | --- | --- |
| `caption` | `string` | Yes | — |
| `columns` | `DataTableColumn[]` | Yes | — |
| `rows` | `Record<string, string \| number \| null \| undefined>[]` | Yes | — |
| `emptyMessage` | `string` | No | `"No data available."` |

```ts
interface DataTableColumn {
  key: string;
  label: string;
  align?: "start" | "center" | "end";
}
```

The caption is visually hidden but remains available to assistive technology. The frame scrolls horizontally on narrow screens.
