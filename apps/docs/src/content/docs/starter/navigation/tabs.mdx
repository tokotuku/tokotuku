## Props

| Prop | Type | Required | Default |
| --- | --- | --- | --- |
| `items` | `TabItem[]` | Yes | — |
| `label` | `string` | No | `"Page sections"` |

```ts
interface TabItem {
  label: string;
  href: string;
  active?: boolean;
  count?: number;
}
```

These are navigation links rather than ARIA tab widgets, so they work for server-rendered pages and URL fragments without client state.
