`AppInput` forwards all props to the core [`TkInput`](/components/input/), keeping starter forms independent from the underlying package import.

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `label` | `string` | `""` |
| `type` | `"text" \| "email" \| "password"` | `"text"` |
| `name` | `string` | `""` |
| `value` | `string` | `""` |
| `placeholder` | `string` | `""` |
| `required` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |

The underlying element dispatches the typed `tk-change` event and exposes `focus()`.
