## Available components

- [`Button`](/components/button/) — native actions with three variants and sizes.
- [`Input`](/components/input/) — labeled native input fields.
- [`Card`](/components/card/) — a composable media, body, and footer article.

## Starter component library

The commerce starter also includes 15 application-level Astro components for dashboards and storefronts. Browse them under **Starter components** in the sidebar.
