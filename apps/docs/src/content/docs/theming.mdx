Tokotuku uses Tailwind CSS v4 theme variables plus semantic `--tk-*` CSS custom properties for
runtime color modes.

## Load the global stylesheet

Import the UI stylesheet once from the application layout:

```astro
---
import "@tokotuku-starter/ui/styles.css";
---
```

The stylesheet imports Tailwind, defines its `@theme` utilities, and contains all Tokotuku color
modes. Components remain zero-runtime; Tailwind generates static CSS during the Vite build.

## Select a palette

Set `data-theme` on an ancestor, normally the root element:

```html
<html data-theme="light">...</html>
<html data-theme="dark">...</html>
<html data-theme="high-contrast">...</html>
```

When `data-theme` is absent, the theme follows `prefers-color-scheme`.

## Override tokens

CSS custom properties cascade through the native HTML rendered by Astro components:

```css
.checkout-actions {
  --tk-color-accent: #7c3aed;
  --tk-color-accent-fg: #ffffff;
  --tk-radius-md: 999px;
}
```

Prefer semantic variables such as `--tk-color-accent` and `--tk-color-danger`; components intentionally do not depend on raw palette values.
