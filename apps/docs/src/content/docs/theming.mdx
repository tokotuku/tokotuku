Tokotuku uses Tailwind CSS v4 theme variables plus semantic `--tk-*` CSS custom properties for
runtime color modes.

## Load the global stylesheet

Import the UI stylesheet once from the application layout:

```astro
---
import "@tokotuku/ui/styles.css";
---
```

The stylesheet imports Tailwind, defines its `@theme` utilities, and contains all Tokotuku color
modes. Components remain zero-runtime; Tailwind generates static CSS during the Vite build.

## Select a palette

Set `data-theme` on an ancestor, normally the root element:

```html
<html data-theme="light">...</html>
<html data-theme="dark">...</html>
<html data-theme="high-contrast">...</html>
```

When `data-theme` is absent, the theme follows `prefers-color-scheme`.

## Override tokens

CSS custom properties cascade through the native HTML rendered by Astro components:

```css
.checkout-actions {
  --tk-color-accent: #7c3aed;
  --tk-color-accent-fg: #ffffff;
  --tk-radius-md: 999px;
}
```

Prefer semantic variables such as `--tk-color-accent` and `--tk-color-danger`; components intentionally do not depend on raw palette values.

## Branding and auth imagery

The `brand` option is backward-compatible. The `auth` block is optional; when no image is configured (or the image cannot load), auth uses its built-in warm gradient.

```js
tokotuku({
  brand: {
    name: "Kedai Senja",
    locale: "id-ID",
    currency: "IDR",
    timeZone: "Asia/Jakarta",
    auth: {
      backgroundImage: "/images/auth-commerce.webp",
      backgroundPosition: "center 35%",
    },
    messages: {
      "auth.login.title": "Masuk ke ruang kerja {brand}",
      "admin.nav./admin/orders": "Penjualan",
    },
  },
  modules: [auth(), catalog(), orders()],
})
```

`backgroundImage` accepts a public path or absolute URL and is rendered as a decorative image (not interpolated into CSS). On small screens it becomes a blurred, faded backdrop behind the form. `messages` is a sparse override map: defaults are selected from the locale (`id*` uses Indonesian, everything else uses English), and unknown keys are ignored in production (with a development warning). `{brand}`, `{name}`, `{count}`, `{from}`, and `{to}` placeholders are supported.

For the fallback gradient, omit `auth` entirely:

```js
brand: { name: "Kedai Senja", locale: "id-ID", currency: "IDR" }
```
