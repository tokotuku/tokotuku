## Yang disediakan Karsa

- UI dan theme Astro bertipe dengan primitive aksesibel.
- Modul opsional dengan kontribusi registry, urutan dependency, migrasi, dan seed.
- Pola konten serta halaman yang memisahkan halaman milik aplikasi dari route milik modul.
- Alur kerja AI dengan asumsi, bukti, validasi, serta keputusan scope yang tercatat.

Gunakan panduan untuk memilih preset, lalu ikuti kontrak yang sesuai untuk konten, data, dan deployment situs.
