Props wajibnya `caption`, `columns`, dan `rows`; `emptyMessage` opsional. Kolom memiliki `key`, `label`, serta alignment `start`, `center`, atau `end`. Caption disembunyikan secara visual tetapi tersedia untuk assistive technology. Frame dapat di-scroll horizontal pada layar sempit.
