```astro
<ProductCard
  id={product.id}
  name={product.name}
  description={product.description}
  price={currency.format(product.priceCents / 100)}
  priceCents={product.priceCents}
  imageUrl={`/api/images/${product.imageKey}`}
/>
```

`id`, `name`, `description`, `price`, `priceCents`, dan `imageUrl` diperlukan. Tombol add menyerialisasi data produk ke `data-product`; `SiteHeader` menangani event dan cart lokal.
