```astro
<Pagination page={2} totalPages={8} baseUrl="?page=" />
```

`page` dan `totalPages` wajib; `baseUrl` default-nya `?page=`. Link sebelumnya dan berikutnya mengekspos `aria-disabled="true"` di batas koleksi dan berada dalam navigasi berlabel “Pagination”.
