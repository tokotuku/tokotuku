`items` wajib dan memiliki `label`, `href`, serta `active` atau `count` opsional. `label` opsional default-nya “Page sections”. Ini adalah link navigasi, bukan widget ARIA tab, sehingga bekerja untuk halaman server-rendered dan URL fragment tanpa state client.
