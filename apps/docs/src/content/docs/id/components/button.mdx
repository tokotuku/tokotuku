`Button` menghasilkan `<button>` native. Gunakan untuk aksi, submit form, atau reset; gunakan link ketika pengguna berpindah halaman.

```astro
---
import Button from "@karsa/ui/Button.astro";
---

<Button variant="primary" size="md">Simpan perubahan</Button>
```

| Properti | Tipe | Default |
| --- | --- | --- |
| `variant` | `"primary" \| "secondary" \| "ghost"` | `"primary"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `type` | tipe button native | `"button"` |
| Properti lain | atribut `<button>` native | — |

Default slot menerima label atau konten inline. Aktivasi keyboard, `disabled`, `aria-*`, dan focus-visible native tetap dipertahankan.
