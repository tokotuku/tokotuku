---
title: Mode registrasi auth
description: Pilih registrasi public atau closed dan pahami alur setup sekali pakai.
---

Modul auth memiliki dua mode registrasi eksplisit. Pilih di konfigurasi modul; jangan menyembunyikan kebijakan di komponen halaman.

```js
import { auth } from "@karsa/auth";

karsa({ modules: [auth({ registration: "public" })] });
```

| Mode | `/register` | Kegunaan |
| --- | --- | --- |
| `public` | Tersedia | Siapa pun boleh membuat akun; route berprivilege tetap harus dilindungi session/access check. |
| `closed` | Tidak di-inject | Admin atau proses identity eksternal membuat akun. |

## Setup pertama

Kedua mode menyediakan alur `/setup` sekali untuk administrator pertama. Alur mengklaim setup gate sebelum membuat akun. Pastikan `BETTER_AUTH_SECRET` sudah diatur sebelum deploy, dan jangan pernah melakukan seed password aktif ke repository.

Halaman login hanya menampilkan link registrasi pada mode public. Uji kedua mode: injection route, perilaku API, copy login, access control, dan setup gate. Jika kebutuhan invite-only muncul, gunakan `closed` dan dokumentasikan mekanisme invite, bukan merender form public diam-diam.
