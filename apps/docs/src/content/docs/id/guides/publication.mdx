Preset publication berfokus pada konten. Perlakukan artikel, author, tag, feed, dan tanggal rilis sebagai data editorial, bukan katalog produk terselubung.

## Ownership konten

Simpan entry sumber di content layer dan biarkan aplikasi bertanggung jawab atas shell, navigasi, landing page, dan layout baca. Gunakan panduan penulisan konten/blog untuk frontmatter dan check editorial. Publikasi tidak membutuhkan modul catalog, order, atau booking kecuali brief terpisah benar-benar memperkenalkan domain tersebut.

## Tier

- Install: validasi content loader, route, tema, dan registry.
- Content: tambahkan artikel, author, tag, deskripsi, dan gambar yang disetujui.
- Polished: atur tipografi, lebar baca, dan imagery editorial tanpa membuat abstraksi CMS terlalu dini.

Periksa canonical URL, heading, alt text, tanggal sesuai locale, output feed, draft, broken link, typecheck, lint, dan build. Laporkan input editorial yang belum ada, jangan mengarangnya.
