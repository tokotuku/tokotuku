## Props

| Prop | Type | Required | Default |
| --- | --- | --- | --- |
| `page` | `number` | Yes | — |
| `totalPages` | `number` | Yes | — |
| `baseUrl` | `string` | No | `"?page="` |

Previous and next links expose `aria-disabled="true"` at the collection boundaries and are wrapped in navigation labeled “Pagination”.
