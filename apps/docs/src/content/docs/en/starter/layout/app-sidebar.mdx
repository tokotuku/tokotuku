## Props

| Prop | Type | Required | Default |
| --- | --- | --- | --- |
| `brand` | `string` | No | `"Karsa"` |
| `items` | `NavigationItem[]` | Yes | — |

```ts
interface NavigationItem {
  label: string;
  href: string;
  active?: boolean;
  badge?: string;
}
```

The optional `footer` slot stays at the bottom of the sidebar on desktop and is hidden in the compact mobile layout.
