## Props and slots

| Name | Kind | Required | Purpose |
| --- | --- | --- | --- |
| `title` | Prop (`string`) | Yes | Primary empty-state message |
| `description` | Prop (`string`) | No | Supporting explanation |
| `icon` | Slot | No | Decorative icon; defaults to a dot |
| `actions` | Slot | No | Recovery or creation actions |
