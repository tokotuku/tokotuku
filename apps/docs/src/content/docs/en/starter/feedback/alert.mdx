## Props

| Prop | Type | Default |
| --- | --- | --- |
| `tone` | `"info" \| "success" \| "warning" \| "danger"` | `"info"` |
| `title` | `string` | — |

The default slot contains the message. Danger alerts use `role="alert"`; other tones use `role="status"`.
