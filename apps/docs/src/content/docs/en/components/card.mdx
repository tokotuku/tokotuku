`Card` provides semantic `<article>` structure without imposing domain-specific interactions.

```astro
---
import Button from "@karsa/ui/Button.astro";
import Card from "@karsa/ui/Card.astro";
---

<Card>
  <img slot="media" src="/object.jpg" alt="Everyday object" />
  <h2>Everyday object</h2>
  <p>Reliable, compact, and ready for daily use.</p>
  <div slot="footer"><Button size="sm">View details</Button></div>
</Card>
```

| Slot | Purpose |
| --- | --- |
| `media` | Image, video, illustration, or other leading media |
| default | Main body content |
| `footer` | Actions, metadata, or supporting content |

The footer is omitted when empty. Supply your own semantic heading; `Card` does not invent one.
