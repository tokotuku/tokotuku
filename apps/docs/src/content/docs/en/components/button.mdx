`Button` renders a native `<button>`. Use it for an action, form submission, or reset; use a link when the user is navigating.

```astro
import Button from "@karsa/ui/Button.astro";

<Button variant="primary" size="md">Save changes</Button>
```

## Properties

| Property | Type | Default |
| --- | --- | --- |
| `variant` | `"primary" \| "secondary" \| "ghost"` | `"primary"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `type` | native button type | `"button"` |
| Remaining props | native `<button>` attributes | — |

The default slot accepts a label or inline content. Native keyboard activation, `disabled`, `aria-*`, and focus-visible behavior are preserved.
