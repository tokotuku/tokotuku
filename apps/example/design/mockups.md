# Tokotuku UI overhaul mockups

Generated with the built-in ImageGen tool on 2026-08-15 as visual direction for the storefront and admin overhaul.

## `tokotuku-overhaul-before-seed.png`

High-fidelity concept board for a fresh installation with zero products. The storefront remains visually complete through an editorial hero, intentional empty collection state, trust content, newsletter, and footer. The admin uses onboarding progress, quick actions, a launch checklist, store preview, and zero-state metrics instead of empty tables.

Palette: warm ivory, ink charcoal, paper white, muted clay, and subtle sage. Editorial serif typography is paired with a modern sans-serif. Avoid glassmorphism, neon, oversized pills, excessive gradients, clutter, fake products, and placeholder copy.

## `tokotuku-overhaul-after-seed.png`

Populated companion state derived from the before-seed mockup. It preserves the same design system and composition while adding six art-directed demo products to the storefront and useful operational data to the admin: sales metrics, revenue chart, recent orders, low-stock alerts, top products, and quick actions.

The seeded state must feel like content entering an already-finished product, not like seed data repairing an unfinished interface.
