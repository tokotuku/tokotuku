# Component Storybook

The starter's complete local Astro component package runs in Storybook through
`@storybook-astro/framework`; no package publishing step is required.

```sh
bun run storybook
```

Storybook requires Node.js 20.16+, 22.19+, or 24+. A static build is available through
`bun run storybook:build`.
