# Karsa logo alternatives

Exploration only. These transparent PNG lockups do not replace the canonical assets one directory above.

| direction | idea | character |
| --- | --- | --- |
| 01 Anyam | Three interlocking fields with an open central weave | Bold, recognizably Karsa, scalable |
| 02 Tunas | Stem and two leaf-like facets | Warm, optimistic, organic |
| 03 Ruang | Monochrome cut-out K held by a calm rounded frame | Simple, assured, app-ready |
| 04 Kompas | Directional diamond facets | Precise, modular, infrastructural |
| 05 Alur | Continuous rounded route | Friendly, connected, service-oriented |

All five lockups use the current teak `#7A4B32`, ivory `#F7F0E4`, and Manrope Semibold wordmark so the symbol is the main comparison variable. Each individual PNG is `1440 × 512` with a transparent background; the comparison sheet uses an ivory background.

Direction `03 Ruang` was polished after review and selected as the canonical identity on 2026-08-24. The clay corner was removed, the K was optically centered, the diagonal reach was shortened, and the wordmark spacing was tightened. Its PNG-only review set includes:

- `karsa-alt-03-ruang.png` — teak horizontal lockup on transparency
- `karsa-alt-03-ruang-dark.png` — ivory horizontal lockup on transparency
- `karsa-alt-03-ruang-mark.png` — standalone `1024 × 1024` teak mark
- `karsa-alt-03-ruang-polished-preview.png` — light/dark and small-size review sheet
